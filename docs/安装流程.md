# 完整安装流程（正确顺序）

> 本文只讲**怎么装**。装之前请确认：Windows 10/11 x64、微信 **4.1.10.27**（目录名必须是 `4.1.10.27`）、Node.js ≥ 20、Python 3.11（语音合成/识图用）。
>
> 两条路线二选一：
> - **A. 用成品包**（不会编译也能装）：拿到 `大肥鱼的眼睛.zip`（含编译好的 `version.dll` + 一键安装/回滚脚本）
> - **B. 自己编译 hook**：有源码 + 补丁，用 VS2022 Build Tools 编出 `version.dll`

---

## 一、先理解整体结构

```
微信客户端 (Weixin.exe)
   └─ 同目录 version.dll  ← hook 代理：消息/数据库/发送/眼睛
        ├─ HTTP 接口 127.0.0.1:30001   （读库 / 发消息 / 诊断）
        └─ 消息回调 127.0.0.1:18998    （新消息推给桥）

wx-bridge（Node.js）ws://127.0.0.1:17300
   ├─ 连 30001 读写微信
   └─ 连 DSH 插件（WebSocket 17300）

DSH + wechat-group-agent 插件
   └─ 控制面板 /wechat-bot
```

**没有 `version.dll` 就什么都做不了**（读不到消息、发不出消息）。

---

## 二、安装 hook（version.dll）

### 2.1 路线 A：用成品包

1. 解压 `大肥鱼的眼睛.zip` 到任意目录（**不要解压到 `%TEMP%`**，Defender 可能把里面的 dll 当可疑文件删掉）
2. 完全退出微信（托盘右键 → 退出微信），确认任务管理器里 `Weixin.exe` 进程数为 0
3. 运行 `一键安装.ps1`（会自动备份旧 dll 再覆盖）；或手动把 `version.dll` 复制到微信目录
4. 安装完成后，确认微信目录里有：
   ```
   version.dll
   hook-cdn-replay.on      ← 眼睛重放开关
   hook-cdn-replay.dir     ← 重放缓存目录（内容 D:\cdndl-replay）
   ```

### 2.2 路线 B：自己编译（从原版源码到能用的 version.dll）

**先说结论：原版 hook 编出来的 DLL 不能直接用于本机器人。**

原版（aixed/WeChat-Hook）缺这几样，直接用会表现为「机器人不说话」：

- 与微信 **4.1.10.27** 对应的 sqlite API 偏移校准
- 数据库开库钩子（open16/open）+ late-arm 补装（否则读不到 contact.db）
- `/SendVoiceMsg`（真语音气泡）、`/Debug/VuProbe`（眼睛）、`/Debug/DBRescan`（诊断）
- 本项目对发送/查询接口的若干修正

因此：**源码 + 本项目补丁缺一不可**。补丁含 RVA 偏移，属私有资产，不随公共仓库发布，需要向作者索取。

#### 需要准备

1. Windows 10 / 11 x64
2. **Visual Studio 2022 Build Tools**（不必装完整 VS），安装时勾选：
   - 「使用 C++ 的桌面开发」（MSVC v143）
   - Windows 10 / 11 SDK
3. Git for Windows
4. 源码：`aixed/WeChat-Hook`（公开原版）+ 本项目补丁（私有）

#### 编译步骤

```powershell
# 1) 拉原版源码
git clone https://github.com/aixed/WeChat-Hook.git wxhook-src
cd wxhook-src

# 2) 应用本项目补丁（补丁文件由作者提供）
git apply --check patches/wechat-hook-querydb-fix.patch   # 先确认能干净应用
git apply         patches/wechat-hook-querydb-fix.patch

# 3) 定位 MSBuild（用 vswhere，别猜路径）
$vswhere = "${env:ProgramFiles(x86)}\Microsoft Visual Studio\Installer\vswhere.exe"
$msbuild = & $vswhere -latest -requires Microsoft.Component.MSBuild `
            -find "MSBuild\**\Bin\MSBuild.exe" | Select-Object -First 1

# 4) 编译（Release x64）
& $msbuild x64_Version_dll.sln /p:Configuration=Release /p:Platform=x64 /m

# 5) 取产物
Get-Item .\x64\Release\version.dll    # 约 770~780KB
```

#### 编译成功的最低校验

- `x64\Release\version.dll` 存在且 > 700KB
- 部署并启动微信后，`http://127.0.0.1:30001/QueryDB/status` 能返回 JSON
- 返回 404 / 连接拒绝 → DLL 没被加载：检查是否放在 `Weixin.exe` 同目录、微信是否 4.1.10.27

#### 常见编译错误

| 报错 | 原因 | 处理 |
|---|---|---|
| `MSB8020：找不到 v143 工具集` | 没装 C++ 工作负载 | VS Installer 勾「使用 C++ 的桌面开发」 |
| `无法打开 include 文件 "httplib.h"` | 子模块没拉 | `git submodule update --init --recursive` |
| `C1083：无法打开 "Windows.h"` | 缺 Windows SDK | 勾选 Windows 10/11 SDK |
| `LNK1104：无法打开 version.lib` | 中间产物/旧库冲突 | 删掉 `x64\` 目录后重新编译 |
| 编译成功但微信启动即崩 | 源码与微信版本不匹配 | 必须是 4.1.10.27；换对应版本源码 |

#### 部署

按 2.1 的第 2~4 步：**完全退出微信 → 覆盖 `version.dll` → 启动**。

> 不会编译也没关系：直接用 2.1 的成品包，里面就是编译好、已验证的 DLL。

## 三、启动微信（必须带 hook 参数）

```powershell
Start-Process -FilePath 'D:\wxhook\wx4110\Weixin.exe' -ArgumentList `
    'StartPort=30001','RecvType=1','CallBackURL=http://127.0.0.1:18998/recv' `
    -WorkingDirectory 'D:\wxhook\wx4110'
```

- 登录窗口出现时点 **「进入微信」**
- 验证 hook 已加载：
  ```powershell
  Invoke-RestMethod http://127.0.0.1:30001/QueryDB/status
  # 期望：{"IsLogin":1,...}
  ```

> ⚠️ **登录成功后，务必在微信里点一次左侧「通讯录」图标，停留 3 秒。**
> 微信的 `contact.db` 只在打开通讯录/搜索联系人时才真正打开；
> 不点这一步，桥会报 `get database handle which named contact.db failed`，
> 表现为：群成员为空、名字只显示 wxid、真 @ 退化成纯文本 @。

## 四、启动桥（wx-bridge）

```powershell
cd D:\微信deepseek\wx-bridge
node server.mjs --transport=wechat-hook --api-port=30001 --cb-port=18998 `
     --data-dir=D:\微信deepseek\data --wechat=D:\wxhook\wx4110\Weixin.exe
```

验证：

```powershell
Invoke-RestMethod http://127.0.0.1:17300/status
# 期望：loggedIn=true，clients=1
```

首次启动如果提示「数据库轮询硬停」，在微信里点一次通讯录后执行：

```powershell
Invoke-RestMethod http://127.0.0.1:17300/api/pollResume -Method Post -Body '{}' -ContentType 'application/json'
```

## 五、启动 DSH + 插件

1. 启动 DSH web（默认 `http://127.0.0.1:3080`）
2. 确认插件已装配（profile 的 `cordis.patch.yml` 里有 `dsh-wechat-bot` 条目，且 `disabled` 不为 true）
3. 左侧面板列表应出现 **🐋 微信机器人**，点击打开控制面板
4. 面板「总览」点 **立即自检**，应全部 ✅（`filehelper` 那项提示可忽略——它不是群）

---

## 六、语音发送（默认关闭，需要手动开）

1. 面板「语音」页 → 🔌 hook 语音发送开关 → 打开
2. 该开关会同时创建 `hook-voice-send.on` 标记文件（重启微信后仍生效）
3. 语音页把 `voiceSay` 打开、`voiceSayProbability` 调到想要的值（0.2 = 约 5 条里 1 条用语音）
4. 测试：面板「手动操作」→ 操作选「发语音（合成）」→ 选群 → 输入文字 → 发送

> 合成（TTS）需要联网；合成/发送失败会自动降级发文字，不会丢消息。

## 九、常见坑（都是实际踩过的）

| 现象 | 原因 | 处理 |
|---|---|---|
| `get database handle which named contact.db failed` | 微信还没打开 contact.db | 微信里点一次「通讯录」，再 `POST /api/pollResume` |
| 群成员空、名字是 wxid、@ 变纯文本 | 同上 | 同上 |
| 语音发不出去（ret=-1005 / preflight 失败） | DLL 是旧版（preflight 不放行 0xE9） | 换成本仓库配套的新版 `version.dll` |
| 面板语音开关重启后失效 | 旧版 DLL 只改内存 | 新版会在切换时写 `hook-voice-send.on` 标记文件 |
| 换 dll 报「文件被占用」 | 微信还在跑 | 完全退出微信（进程数 0）再换 |
| 解压出来的 dll 找不到了 | Defender 把 `%TEMP%` 里的 dll 删了 | 解压到微信目录或非 Temp 路径 |
| 面板 🐋 消失，但机器人还在回消息 | 插件 entry 被标了 `disabled: true`（热重载副作用） | 重启 `dsh web`，或让 entry 复位后重新启用 |
| 插件热重载后代码不生效 | ESM 模块缓存没清 | 重载前清 `loader.internal.loadCache` 里该包的缓存 |

## 十、回滚

用成品包里的 `一键回滚.ps1`，或手动：

1. 完全退出微信
2. 把 `version.dll.bak-<时间>` 复制回 `version.dll`
3. 重新启动微信

## 十一、不要上传到 GitHub 的东西

- `version.dll`（hook 二进制）
- `大肥鱼的眼睛*.zip` / 任何 `*.zip`
- `patches/*.patch`（含 Weixin.dll RVA 地址的源码补丁）
- `scripts/gen-offset-patterns.py`（RVA 特征码生成器）
