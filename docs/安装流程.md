# 完整安装流程（正确顺序）

> 本文只讲**怎么装**。配套版本 **v1.4.12**（`version.json` 与插件 `export const version` 必须一致）。
> 装之前请确认：Windows 10/11 x64、微信 **4.1.10.27**（目录名必须是 `4.1.10.27`）、Node.js ≥ 20、Python 3.11（语音合成/识图用）。
>
> 下文用 `<仓库>` 表示你 clone 的位置；本机参考值是 `D:\微信deepseek`。
>
> 两条路线二选一：
> - **A. 用成品**（不会编译也能装）：克隆仓库后直接用 `release/` 目录里的 `version.dll` + `install.ps1`（或从 GitHub Releases 下载同样文件）
> - **B. 自己编译 hook**：从我们的 hook 仓库（[mengyunqwq/wechat-hook](https://github.com/mengyunqwq/wechat-hook)）clone 源码，用 VS2022 Build Tools 编出 `version.dll`

---

## 一、先理解整体结构

```
微信客户端 (Weixin.exe)
   └─ 同目录 version.dll  ← hook 代理：消息/数据库/发送/眼睛
        ├─ HTTP 接口 127.0.0.1:30001   （读库 / 发消息 / 诊断）
        └─ 消息回调 127.0.0.1:18998    （新消息推给桥）

wx-bridge（Node.js）ws://127.0.0.1:17300
   ├─ 连 30001 读写微信
   └─ 连 DSH 插件（WebSocket 17300）

DSH + wechat-group-agent 插件
   └─ 控制面板 /wechat-bot
```

**没有 `version.dll` 就什么都做不了**（读不到消息、发不出消息）。

---

## 二、安装 hook（version.dll）

### 2.1 路线 A：用成品包

1. 解压 `大肥鱼的眼睛.zip` 到任意目录（**不要解压到 `%TEMP%`**，Defender 可能把里面的 dll 当可疑文件删掉）
2. 完全退出微信（托盘右键 → 退出微信），确认任务管理器里 `Weixin.exe` 进程数为 0
3. 运行 `install.ps1`（一键安装）（会自动备份旧 dll 再覆盖）；或手动把 `version.dll` 复制到微信目录
4. 安装完成后，确认微信目录里有：
   ```
   version.dll
   hook-cdn-replay.on      ← 眼睛重放开关
   hook-cdn-replay.dir     ← 重放缓存目录（内容 D:\cdndl-replay）
   ```

### 2.2 路线 B：自己编译（用我们自己的 hook 仓库，推荐给想改代码的人）

本项目的 hook **已经开源在我们自己的仓库**：

👉 **https://github.com/mengyunqwq/wechat-hook**

它衍生自 [aixed/WeChat-Hook](https://github.com/aixed/WeChat-Hook)，但已经适配微信 **4.1.10.27 x64**
（原版是给 3.9.x 的，直接编译原版接不上——原因见本节末尾）。

#### ① 拉源码并编译

**前置**：Windows 10/11 x64、VS 2022 **Build Tools**（勾「使用 C++ 的桌面开发」+ Windows SDK）、Git。

```powershell
# 1) 拉我们的 hook 仓库（不是 aixed 的）
git clone https://github.com/mengyunqwq/wechat-hook.git wxhook-src
cd wxhook-src

# 2) 子模块（MinHook 等，不拉会编译报错）
git submodule update --init --recursive

# 3) 一条命令编译（脚本会自动找 MSBuild，并打印大小 + SHA256）
pwsh -File scripts\build.ps1

# 产物
Get-Item .\x64\Release\version.dll
```

> 也可以在 bot 仓库根目录直接跑：`pwsh -File scripts\build-hook.ps1`
> 它会自动克隆/更新我们的 hook、编译，并备份+部署到 `D:\wxhook\wx4110`。

#### ② 部署与验证

1. **完全退出微信**（任务管理器里 `Weixin.exe` 进程数为 0）
2. 把 `version.dll` 放进 `Weixin.exe` 同目录（如 `D:\wxhook\wx4110\`）
3. 带 hook 参数启动：

```powershell
Start-Process 'D:\wxhook\wx4110\Weixin.exe' `
  -ArgumentList 'StartPort=30001','RecvType=1','CallBackURL=http://127.0.0.1:18998/recv' `
  -WorkingDirectory 'D:\wxhook\wx4110'
```

4. 验证：

```powershell
Invoke-RestMethod http://127.0.0.1:30001/QueryDB/status
# 期望：{"IsLogin":1,"hWeixin":...}
```

5. **登录后点一次微信左侧「通讯录」**（`contact.db` 只在那时打开；不点的话群成员/昵称/@ 都会退化）。

#### ③ 桥依赖的接口（我们的 hook 已全部实现）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/QueryDB/status` | 登录状态 |
| POST | `/QueryDB/execute` | 执行 SQL |
| POST | `/QueryDB/GetAllDBName` | 库名列表 |
| POST | `/GetSelfProfile` | 自己资料 |
| POST | `/SendTextMsg` | 发文本（支持 atlist 真 @）|
| POST | `/SendImgMsg` | 发图片 |
| POST | `/SendVoiceMsg` | 发语音（真气泡，type 34）|
| POST | `/Decode_Pic` | 图片解密 |
| POST | `/Debug/VoiceSend` | 语音发送开关（可选）|
| POST | `/Debug/DBRescan` | 句柄诊断（可选）|
| GET | `/Debug/VuProbe` | 眼睛 9 钩子状态（可选）|

#### ④ 为什么不能直接用原版 aixed/WeChat-Hook

原版是给微信 **3.9.x** 的，按 4.1.10.27 编译出来也接不上：

1. **偏移不对**：sqlite API 表、发送函数、图片密钥等偏移写死成 3.9.x 的值 → `/QueryDB` 恒报 `get database handle which named contact.db failed`
2. **端点不全**：`/SendVoiceMsg`、`/Decode_Pic`、`/Debug/DBRescan`、`/Debug/VuProbe` 原版都没有
3. **缺 4.x 开库入口**：4.x 主要走 `open16`（宽字符文件名），原版只挂 `open`/`open_v2`，且构造时 API 表还没填好（需要 **late-arm**）

我们的仓库已经把这些全部做完（见 `docs/reverse-notes.md`）。

## 三、启动微信（必须带 hook 参数）

```powershell
Start-Process -FilePath 'D:\wxhook\wx4110\Weixin.exe' -ArgumentList `
    'StartPort=30001','RecvType=1','CallBackURL=http://127.0.0.1:18998/recv' `
    -WorkingDirectory 'D:\wxhook\wx4110'
```

- 登录窗口出现时点 **「进入微信」**
- 验证 hook 已加载：
  ```powershell
  Invoke-RestMethod http://127.0.0.1:30001/QueryDB/status
  # 期望：{"IsLogin":1,...}
  ```

> ⚠️ **登录成功后，务必在微信里点一次左侧「通讯录」图标，停留 3 秒。**
> 微信的 `contact.db` 只在打开通讯录/搜索联系人时才真正打开；
> 不点这一步，桥会报 `get database handle which named contact.db failed`，
> 表现为：群成员为空、名字只显示 wxid、真 @ 退化成纯文本 @。

## 四、启动桥（wx-bridge）

```powershell
cd <仓库>\wx-bridge
node server.mjs --transport=wechat-hook --api-port=30001 --cb-port=18998 `
     --data-dir=<仓库>\data --wechat=D:\wxhook\wx4110\Weixin.exe

# 本机（参考）：cd D:\微信deepseek\wx-bridge
#                --data-dir=D:\微信deepseek\data
```

验证：

```powershell
Invoke-RestMethod http://127.0.0.1:17300/status
# 期望：loggedIn=true，clients=1
```

首次启动如果提示「数据库轮询硬停」，在微信里点一次通讯录后执行：

```powershell
Invoke-RestMethod http://127.0.0.1:17300/api/pollResume -Method Post -Body '{}' -ContentType 'application/json'
```

## 五、启动 DSH + 插件

1. 启动 DSH web（默认 `http://127.0.0.1:3080`）
2. 确认插件已装配（profile 的 `cordis.patch.yml` 里有 `dsh-wechat-bot` 条目，且 `disabled` 不为 true）
3. 左侧面板列表应出现 **🐋 微信机器人**，点击打开控制面板
4. 面板「总览」点 **立即自检**，应全部 ✅（`filehelper` 那项提示可忽略——它不是群）

---

## 六、语音发送（默认关闭，需要手动开）

1. 面板「语音」页 → 🔌 hook 语音发送开关 → 打开
2. 该开关会同时创建 `hook-voice-send.on` 标记文件（重启微信后仍生效）
3. 语音页把 `voiceSay` 打开、`voiceSayProbability` 调到想要的值（0.2 = 约 5 条里 1 条用语音）
4. 测试：面板「手动操作」→ 操作选「发语音（合成）」→ 选群 → 输入文字 → 发送

> 合成（TTS）需要联网；合成/发送失败会自动降级发文字，不会丢消息。

## 七、眼睛（重放）验证

> **现状（v1.4.9 起）**：眼睛能力已**内置进成品 hook**，不需要再拖 zip 安装；
> 面板上原有的「眼睛」页（7 个 op：eyesUpload/eyesInstall/eyesInfo/eyesSetDir/eyesToggle/eyesClean/eyesCheck）
> 已随页面一起删除。装配时 `install.ps1` 会自动写好重放开关文件。

```powershell
Invoke-RestMethod http://127.0.0.1:30001/Debug/VuProbe
# 期望：installed=true, hooksOk=9 / hooksTotal=9
```

重放开关文件（`install.ps1` 负责创建，可手动改）：

```
<微信目录>\hook-cdn-replay.on
<微信目录>\hook-cdn-replay.dir   → 内容为缓存目录，例如 D:\cdndl-replay
```

## 九、常见坑（都是实际踩过的）

| 现象 | 原因 | 处理 |
|---|---|---|
| `get database handle which named contact.db failed` | 微信还没打开 contact.db | 微信里点一次「通讯录」，再 `POST /api/pollResume` |
| 群成员空、名字是 wxid、@ 变纯文本 | 同上 | 同上 |
| 语音发不出去（ret=-1005 / preflight 失败） | DLL 是旧版（preflight 不放行 0xE9） | 换成本仓库配套的新版 `version.dll` |
| 面板语音开关重启后失效 | 旧版 DLL 只改内存 | 新版会在切换时写 `hook-voice-send.on` 标记文件 |
| 换 dll 报「文件被占用」 | 微信还在跑 | 完全退出微信（进程数 0）再换 |
| 解压出来的 dll 找不到了 | Defender 把 `%TEMP%` 里的 dll 删了 | 解压到微信目录或非 Temp 路径 |
| 面板整站 404（🐋 消失） | 热重载在旧版本里会拆掉旧实例却建不起新实例（1.4.10/1.4.11） | 升级到 **≥1.4.12**（热重载只预检、不自替换）；已经 404 就**重启 DSH** 一次 |
| 点了「热重载插件」但代码没生效 | 1.4.12 起它**只做预检**（插件无法安全替换自身，见 R17） | 重启 `dsh web` 才生效 |

## 十、回滚

用成品包里的 `rollback.ps1`（一键回滚），或手动：

1. 完全退出微信
2. 把 `version.dll.bak-<时间>` 复制回 `version.dll`
3. 重新启动微信

## 十一、不要上传到 GitHub 的东西

- `version.dll`（hook 二进制）
- `大肥鱼的眼睛*.zip` / 任何 `*.zip`
- `patches/*.patch`（含 Weixin.dll RVA 地址的源码补丁）
- `scripts/gen-offset-patterns.py`（RVA 特征码生成器）
- `docs/*-re.md`（逆向笔记）
- `config.json`（真实 wxid / 密钥 / 本机路径）
