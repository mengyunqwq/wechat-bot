## 三、怎么用

1. 加能力前先搜本文件关键字（`mmsns` / `cdntask` / `aeskey` / `TimelineObject`）
2. 命中后看「引用点 RVA」，用 `python tools_rva_dump.py <dll> <rva> 48` 取码
3. 确认是目标函数后，按 `include/global.h` 的格式加偏移 + 特征码
4. 小号验证 → 回归测试

## 四、朋友圈发图的可行路径（基于本次扫描）

- 图片上传：复用第二节 `媒体/CDN` 里的 **上传** 组（`cdntask upload with buffer`、`safecdn bigfile`）
- 拿到 `fileid + aeskey + cdnurl` 后，写进 `TimelineObject` 的 MediaList
- 再走 `mmsnspost` 提交
- 卡点：`mmsnspost` 的调用在数据表里，需要 Ghidra 追表引用
