# 性格系统（状态机 / 自我叙事 / 好恶 / 私人目标）

> 2026-10-28 上线（**未推送 GitHub**）。代码：`wechat-group-agent/lib/persona.mjs`（纯函数）+ `lib/index.js` 接入。
> 回滚：配置 `personaEnabled=false`（立刻回到"只有人设文案"的旧行为）。

## 为什么需要这个

以前的"人设"只是**一段 prompt**（`你的性格：…`）+ 一堆独立概率参数。它能**演**性格，但长不出性格，因为缺三样：

| 必要条件 | 旧系统 | 现在 |
|---|---|---|
| **一致性** | 无约束，今天话痨明天哑巴 | 5 个状态变量互相牵制 |
| **主观性** | 没有喜欢/讨厌 | 好恶表（会自己长、有权重） |
| **连续性** | 重启即归零 | 状态 + 日记落盘 |

## 四件套

### ② 状态机（连续性）

持久化在 `data/wechat-bot/persona/<room>.json`：

```
mood    { valence: -1~1, arousal: 0~1 }   心情
energy  0~1                                精力
affinity{ wxid: 0~1 }                      对每个人的亲密度
```

更新规则：
- 每条群消息 → 用本地词表判情绪（0 token）→ 心情向该情绪靠拢（强度越大影响越大）
- 冲着我来的正向（被夸）→ 亲密度 +0.07；冲着我来的负向（被骂）→ −0.12
- 时间衰减：心情/亲密度按小时回归基线；精力平时回升、**凌晨反而下降**
- 踩到"讨厌的点" → 心情即刻下降（并记日志）

影响说话方式（写进提示词，不是自由的，是硬约束）：
- 精力 < 0.3 → "很困：句子短、别长篇大论"
- 心情 < −0.25 → "带点刺或敷衍，别强行卖萌"
- 心情 > 0.5 → "愿意多说两句、爱发表情"
- 亲密度 > 0.75 → 对这个人更放松、可以撒娇

### ③ 自我叙事（你无法预设的观点）

每群每 6 小时（`personaDiaryHours`）写一篇 80~160 字日记：

- 输入：当天最近 40 条群聊 + **记忆 v2 检索出来的往事**（带情绪/强度）+ 当前心情 + 好恶 + 目标
- 输出：`{title, text, mood, likes[], dislikes[]}`
- 存 `diary[]`（最近 20 篇），**下次对话把最近 2 篇作为"我的近况"注入**
- 日记里产出的新好恶会自动写回好恶表 —— **这是"性格自己长"的关键通道**

### ④ 好恶（主观性）

```
likes[]    { text, weight, at, source }   最多 8 条
dislikes[] 同上
```

- 初始随机种子：2 个喜欢 + 1 个讨厌（`personaSeedLikes/Dislikes`）
- 增长：① 日记里自己表态 ② 面板手动加 ③ 反复提到 → 同一条权重 +0.15（更在意）
- 行为：喜欢的东西可以主动提；踩到讨厌的点会真不高兴（心情下降）+ 面板可见

### ⑤ 私人目标（动机）

```
goals[]        { id, text, progress 0~3, done }
goalHistory[]  最近 6 个已完成的 id（防止刚做完又被抽回来）
```

目标池：想被夸 / 想知道群里八卦 / 想收集新表情包 / 想有人陪到很晚 / 想学会新梗 / 想被摸头
每个目标带**检测器**：群聊文本命中就推进度（一句话夸三次就推三步），满 3 算达成，随后轮换新目标（避开刚做完的）。

## 面板「💭 内心」页

- **现在**：心情 / 精力进度条 + 高涨度 + 被夸·被伤·收消息·日记数
- **她在意谁**：亲密度 top10（名字已完成映射）
- **好恶**：喜欢/讨厌胶囊（显示权重），可增删
- **她最近想要的**：目标 + 进度条
- **她自己写的日记**：最近 10 篇（时间/标题/心情/正文）
- 按钮：读取 · 写一篇日记（立刻跑一次 LLM）· 换个目标

## 配置（面板可调）

| 键 | 默认 | 说明 |
|---|---|---|
| `personaEnabled` | true | 总开关（关掉行为完全回到旧版） |
| `personaDiaryHours` | 6 | 多久写一篇日记（0=不写） |
| `personaMaxGoals` | 3 | 同时保留几个目标 |
| `personaSeedLikes` | 2 | 初始随机喜欢几条 |
| `personaSeedDislikes` | 1 | 初始随机讨厌几条 |
| `personaMoodFollow` | 0.35 | 情绪对心情的影响强度（越大越情绪化） |

## 新增操作（白名单已放行）

`persona.state` / `persona.diaryWrite` / `persona.tasteAdd` / `persona.tasteRemove` / `persona.goalReroll`

## 安全与成本

- 每群每条消息只做一次本地计算（无 LLM），**落盘节流 60 秒一次**
- 日记：每群每 6 小时 1 次 LLM（约 1.5k token 输入 / 200 输出）
- 写在提示词里的内在状态块约 200~350 token（<900 字符，已测）
- 全部可选关闭；`personaEnabled=false` 即完全回滚

## 验证

- `lib/persona.mjs` 单测 **33/33**（初始化/情绪影响/亲密度/时间衰减/夜间精力/好恶成长去重限量/好恶命中/目标进度与轮换/日记解析追加上限/提示词块）
- 修掉两个实测暴露的 bug：
  1. 目标进度一次只 +1（"真棒 好厉害 喜欢你" 应该推 3 步）
  2. **目标达成后被轮换又会抽回同一个** → 加 `goalHistory` 排除（否则她一遍遍追同一件事）
- 白名单 43/43（47 项）、语法全通过、面板 2.4ms 响应

## 还没做的（方案 6）

**反馈驱动的性格漂移**：记录每句话之后的真实反馈（被接话/被无视/被夸/被怼），做强化学习式的权重微调。
这是唯一能"自己长歪"的机制，风险最高，按约定最后做。

# 自传（she writes her own setting）

> 2026-10-28 追加。目标：**人设的作者从"你"变成"她自己"**。

## 分层（关键：谁是作者）

```
persona（你写的 core）   身份 + 底线          ← 她改不了，永远锁死
narrative（她自己写）    "我是个什么样的人"    ← 随经历演化、有版本历史
state（状态机）          此刻心情/精力/亲密度   ← 每小时都在变
```

提示词顺序：`你的性格(core)` → `【你对自己的认识】（自传）` → `【你现在的心情/好恶/目标/近况】`
说话语气冲突时**状态优先**；身份冲突时**core 优先**；禁止项**core 优先**。

## 触发

- 每个群独立：**攒够 3 篇新日记 + 距上次 ≥24 小时**才会重写（`personaNarrativeHours / personaNarrativeMinDiaries`）
- 定时器每小时检查一次；面板也可「重写自传」立刻跑

## 两道护栏（不通过就保留旧版）

| 护栏 | 规则 | 拒绝示例 |
|---|---|---|
| **身份锚点** | 从 core 里自动抽出「鲸鱼娘/大肥鱼/尾鳍/白饭/主人」等词，自传里至少要有其一 | 写成"我是一朵云"→ 拒 |
| **出戏词** | 出现「程序/AI/人工智能/语言模型/助手/我没有感情」→ 拒 | "我其实是个程序"→ 拒 |
| **人格突变** | 与上一版中文 2-gram Jaccard 相似度 < 0.55 → 拒（`personaNarrativeMaxDrift`） | 换了个完全不同的人 → 拒 |
| 长度 | 40~600 字 | 敷衍一句 → 拒 |

拒绝时日志：`自传被护栏拦下（保留旧版 vN）：<原因>`

## 版本与回滚

- 每次重写 `version + 1`，历史保留最近 12 版
- 面板可选任意历史版本「回滚」→ **作为新的一版写回**（v+1，`restoredFrom: 旧版本号`），历史不丢
- 文件：`data/wechat-bot/persona/<room>.json` 的 `narrative` 字段

## 面板

「💭 内心」页新增 **🪞 自传** 卡片：

- 当前版本号 + 时间 + 正文
- 历史版本下拉 + 「回滚到这一版」
- 顶部「重写自传」按钮（带确认提示：说明身份底线不会被改、突变会被拒、旧版都留着）

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `personaSelfNarrative` | true | 自传总开关 |
| `personaNarrativeHours` | 24 | 多久允许重写一次 |
| `personaNarrativeMinDiaries` | 3 | 至少攒够几篇新日记 |
| `personaNarrativeMaxDrift` | 0.55 | 与上一版最低相似度（越低越敢变） |

## 验证

自传相关断言 12/12：锚点抽取、正常通过、出戏词拒绝、身份丢失拒绝、漂移不崩、
写入 v1、写入 v2 且保留历史、回滚成新版本 v3、回滚不存在版本被拒、重写闸门（刚写过/够时间+够日记）。

## 建议（重要）

现在的 `persona` 是 260 字，**里面一大半是性格形容词**（傲娇又甜、聪明但懒、嘴硬心软、会撒娇）。
自传一旦开始写，这些会跟它抢戏。建议把 `persona` 瘦到约 120 字，只留：

```
① 我是谁（鲸鱼娘/大肥鱼/尾鳍，只自称"鲸鱼娘"）
② 我的世界（人生大事吃白饭；梦云是主人，只叫他主人）
③ 说话习惯（碎句、少标点、口语、偶尔口癖）
④ 我不做的（不聊技术实现、不当客服、不承认是程序）
```

删掉的性格形容词 → 转成"初始倾向"：精力基线调低（懒）、好恶加「被当面拆台」（傲娇）、
目标池加「想被夸」（爱被夸）。这样它们**会被经历验证，也会被经历改写** —— 那才是性格。

# 一个人，不分群（统一人格 + 精力负荷）

> 2026-10-28 追加。原则：**她是一个人，不是每个群一个分身**。

## 已经统一的东西

| 东西 | 存储 | 作用域 |
|---|---|---|
| 长期记忆 | `facts/_all.json` | 全局（一条记忆，所有群可用） |
| 心情 / 精力 / 亲密度 | `persona/_global.json` | 全局 |
| 好恶 / 私人目标 / 自传 | 同上 | 全局 |
| 日记 | 同上 | 全局 |
| 性格漂移 traits | 同上 | 全局 |
| 短期消息上下文 | 每群内存 | **仍按群**（这是"当前在跟谁聊"，本来就该分开） |

配置 `memoryScope='room'` 可整块退回每群独立（不推荐）。

## 精力：按"消息速率 + 活跃群数"算，不再按条数扣

**旧模型的问题**：每条消息固定扣 0.4% 精力 → 三个群一起聊 = 三倍消耗 → 她长期"快困死了"，
这不是"一个人应付几摊事"，是"体力按群线性叠加"。

**新模型**：

```
容量 capacity = 6 条/分钟 × (1 + 0.6 × (活跃群数 − 1))     ← 群越多，单位时间能处理的越多
负荷 load     = 当前速率(EMA) / capacity
精力 target   = 1 − load×(1 − 0.15)   （最低 0.15，再忙也不会彻底没电）
夜间额外下调 0.25
精力向 target 平滑靠拢（不是硬扣），闲置 2 小时以上自动回血
```

实测对比（同样每条 12 秒说一句）：

| 场景 | 负荷 | 40 条后精力 |
|---|---|---|
| 1 个群 | 83% | 17% |
| 3 个群 | 38% | 62% |

即：**同样热闹，群多反而更扛得住** —— 因为她是一个"同时在应付几摊事"的人。

## 提示词

同时活跃 ≥2 个群时，注入一句：

> 【你同时在 N 个群里聊天】都是一个你，不是分身；记忆、脾气、喜好全都通用。

## 面板

「💭 内心」→「现在」卡片多一行：

> ⚡ 3 个群同时在聊｜约 5.0 条/分钟（容量 13.2）｜负荷 38%｜精力 62%

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `personaEnergyBasePerMin` | 6 | 单群时每分钟多少条算满负荷 |
| `personaEnergyRoomBonus` | 0.6 | 每多一个活跃群，容量 +60% |
| `personaEnergyMaxRooms` | 8 | 活跃群数上限 |

## 验证

`test-load.mjs` 9/9：容量随群数增长、有上限、多群更扛得住、狂刷会累但有下限（0.15）、
闲置回升、凌晨更容易困。persona 33/33、traits 19/19、memory-v2 20/20 全过。
