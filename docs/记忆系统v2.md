# 记忆系统 v2 —— 艾宾浩斯遗忘曲线 + 情绪加权

> 2026-10-28 上线（**尚未推送 GitHub**，等确认）。代码：`wechat-group-agent/lib/memory-v2.mjs`（纯函数）+ `lib/index.js` 接入。

## 1. 它和旧系统的区别

| | 旧（v1） | 新（v2） |
|---|---|---|
| 字段 | `{text, kind, at}` | 加 `id / strength(S) / difficulty / emotion / importance / recallCount / lastRecallAt / pinned / archived / sources` |
| 注入 | `facts.slice(-18)`（**按插入顺序**） | 按 `R×相关性×重要度×情绪` 检索 top N（默认 12） |
| 上限 | 每群 80 条，超出**按时间**硬截丢弃 | 每群 120 条，超出按 **R×重要度** 淘汰进归档 |
| 遗忘 | 无（只是被挤掉） | `R=exp(-t/S)`，权重低 → 归档，30 天后才真删 |
| 学习 | 无 | 被检索进上下文 = 复习 → `S` 变大（间隔重复） |
| 情绪 | 无 | 写入时记录情绪；检索时"同情绪更容易想起" |
| 可解释 | 无 | 面板显示每条的 R / S / 重要度 / 用过几次 |

## 2. 数学

```
保持率      R(t) = exp(-t / S)                       t、S 都按"天"
初始强度    S0 = baseDays × (0.5 + importance) × (1 + emotionBoost × 情绪强度)
复习增益    S ← S × (1 + γ × (1 - R) × (1 - difficulty))       γ=1.2
遗忘判据    权重 = R × importance < forgetWeight(0.06) → 归档
容量淘汰    每群 > maxActive(120) → 按权重升序淘汰
铁律        importance ≥ 0.85 → 永不自动归档、不被淘汰
最短保留    不足 minAgeDays(2) 天 → 不归档（给新记忆被用到的机会）
```

默认 `baseDays=7`：第 7 天保持率 37%、第 14 天 13%。这些是"被提炼过的事实"，比随机字符串该记得久。

## 3. 情绪怎么挂钩

**写入**：提炼时让模型对每条记忆多回 3 个字段（同一次调用，不多花钱）：

```
{"text":"...","kind":"fact|pref|event|relation","emotion":"开心|生气|...","emotionIntensity":0.7,"importance":0.8,"selfRelevant":true}
```

规则校正（防模型忽高忽低）：

```
importance = clamp(0.45×模型 + 0.35×情绪强度 + 0.20×自我相关)
"记住这个/别忘了/一定要记得" → importance=0.95 且 pinned
```

**读取**：当前这句话用本地词表粗判情绪（`guessEmotion`，0 token），与记忆的 `(valence, arousal)` 算相似度 → 同情绪优先想起（mood-congruent recall）。**情绪只参与检索加权，不写进提示词**，判错也不影响文案。

## 4. 检索打分

```
score = 0.30·R + 0.35·相关性 + 0.20·重要度 + 0.10·情绪匹配 (×1.15 若 24h 内新建)
```

保底：`pinned` 必带（≤3 条）+ 高情绪记忆保底 2 条 + 5% 随机探索（防"越热门越热门"）。

相关性是**本地零成本**算法（中文 2-gram / 英文词覆盖率），不引向量库。

## 5. 面板（记忆页）

表格列：记忆 / 类型 / 情绪 / **保持率进度条（R% + S 天数）** / 重要度 / 用过次数 / 操作

操作：**固定**（永不遗忘）· **复习**（手动涨 S）· **归档/恢复**
顶部：生效/归档/固定/铁律条数、平均保持率、**未来 7 天预计遗忘 N 条**、情绪分布
另有：`看已归档` 开关、`跑一次遗忘巡检` 按钮

## 6. 配置（面板「记忆」页可调）

| 键 | 默认 | 说明 |
|---|---|---|
| `memoryV2` | true | 总开关（关掉回旧逻辑） |
| `memoryBaseDays` | 7 | 基准半衰天数 |
| `memoryForgetWeight` | 0.06 | 遗忘判据：R×重要度 低于此值 → 归档 |
| `memoryMinAgeDays` | 2 | 最短保留天数 |
| `memoryKeepImportance` | 0.85 | 铁律记忆阈值 |
| `memoryArchiveGraceDays` | 30 | 归档保留天数 |
| `memoryMaxActive` | 120 | 每群生效上限 |
| `memoryInjectCount` | 12 | 每次注入条数 |
| `memoryEmotionBoost` | 0.8 | 情绪对 S0 的加成 |
| `memoryRecallGamma` | 1.2 | 复习增益 γ |
| `memoryPinnedMax` | 3 | 固定记忆必带上限 |
| `memoryConsolidate` | daily | 巡检频率（off/daily/hourly） |

## 7. 迁移与兼容

- 旧 `{text,kind,at}` 在**首次被读到**时自动补字段并落盘（日志：`记忆迁移 v1→v2 …`）
- 迁移来的条目按**当前 baseDays** 重算一次强度（标记 `migratedFrom: v1-rebased`），避免"旧基准 3 天"把老记忆集体判死
- 本机实测：38 条旧记忆归一化后平均强度 7.87 天、平均保持率 92%、未来 7 天预计只遗忘 1 条

## 8. 验证过的东西

- `lib/memory-v2.mjs` 单测 **20/20 通过**（迁移不丢条、R(t) 数学、间隔效应、情绪加权、相关性检索、遗忘/铁律/容量淘汰、统计）
- 真实数据（6 个群 237 条）迁移无丢失
- 检索实测：问"还记得秋北爱发什么"→ 命中秋北那条；问"鱼丸杂鱼杂鱼"→ 命中鱼丸口头禅；问"梦云让我用日语骂人"→ 命中日语那条

# 记忆互通（全局共享）

> 2026-10-28 追加。目标：**她在哪个群都记得**，不再"这个群只知道这个群的事"。

## 改了什么

| 项 | 之前 | 现在 |
|---|---|---|
| 记忆存储 | `facts/<roomId>.json`（每群一份） | `facts/_all.json`（**一份全局库**） |
| 性格状态 | `persona/<roomId>.json` | `persona/_global.json`（心情/好恶/目标/自传/亲密度全共享） |

## 顺带修的两个检索问题（都是实测暴露的）

1. **相关性被新鲜度压制**：原来 rel 只有 0.11（×0.35 也压不过 R 的 ×0.99），
   导致"不管问什么都返回最新几条"。
   → 改成 **IDF 加权相关性**（"梦云""秋北"这类稀有词权重高）+ 权重重排：
   `0.25·R + 0.45·相关性 + 0.20·重要度 + 0.10·情绪`
   实测：问"秋北爱发什么"→ 秋北那条排第 1（rel 0.57）；问"白饭的梗"→ rel 0.84；
   问"鱼丸口头禅"→ rel 0.85，全部命中。
2. **高情绪保底塞进无关记忆**：群里一句"我操我操"（情绪强但和话题无关）会被强制塞进任何提问。
   → 保底改为**必须 rel > 0.05** 才生效。
