大肥鱼的眼睛 —— 让机器人真正看见
================================

本版更新（2026-10-26 · hook 1.2.0 / 机器人 1.4.4）
-----------------------------------
  · ★ 朋友圈自动发布（新功能）：机器人能自己写文案、自己配图、自己发朋友圈
      - 走「消息级驱动」：向微信窗口投递 Windows 消息，不移动鼠标、不抢前台，
        你可以一边用电脑一边让它后台发
      - 支持纯文字，也支持带图（自动填文件对话框，最多多张）
      - 配图走图生图（image-to-image），锁「蓝色大肥鱼」形象，
        不会发成别的动漫角色
      - 界面坐标自适应：发表按钮用微信绿像素定位，菜单按尺寸推算，
        换皮肤/改布局不用重新校准
      - 三道真实校验：编辑器高度、按钮像素命中、发表后编辑器必须关闭，
        杜绝「假成功」
  · 1.4.4 新增：朋友圈改为「群聊事件触发」——不再是到点硬发，
    群里出现好笑的梗/名场面/温情时刻时由 AI 判断值不值得发，值得才发；
    三层闸门（防抖 90s / 同群冷却 30min / 每日额度）+ 文案去重；面板可「试评估」
  · hook 版本 1.2.0（新增 /Moment/PostSilent、/Moment/Ready 接口）
  · SHA256 = 4c382099e0054383…

内容
----
  version.dll      组件本体（图片原图 + 整段视频，约 772KB）
  install.ps1     检查→备份→替换→建开关（右键"使用 PowerShell 运行"）
  rollback.ps1     还原→清开关
  一键接入.md      完整说明（前提/步骤/安全设计/视频处理/故障排查/合规）
  安装说明.md      手动步骤版
  接口说明.md      与 wx-bridge 的契约

三分钟用法
----------
  1) 完全退出微信（托盘右键 → 退出微信）
  2) 右键「install.ps1」→ 使用 PowerShell 运行
  3) 启动微信 → 登录窗口按【回车】
  4) 发一张带文字的截图、发一个短视频（都不用点开）

效果
----
  · 图片：拿到全分辨率原图 → 能读出图里的文字
  · 视频：拿到整段视频 → 每秒 1 帧画面 + 全程台词，不需要点开播放
  · 读完自动删除，不占磁盘

铁律
----
  1) 只适配微信 4.1.10.27（x64），版本不符别装
  2) 装之前必须完全退出微信
  3) 登录窗口直接按【回车】进入
  4) 装完观察 30 分钟 crashinfo\reports，有新 .dmp 立刻回滚
  5) 不要公开分发（上游项目无许可证）
